# 📡 CoolhuntingNow: Intelligence Hub

Plataforma de inteligencia colectiva y análisis de tendencias de **Coolhunting Group**. Diseñada para descodificar el ADN del mañana mediante una arquitectura de alto rendimiento.

## 🚀 Arquitectura Técnica
- **Framework**: Astro (Static Site Generation)
- **CMS**: Strapi (Headless)
- **CDN/Optimización**: Cloudinary
- **Estilos**: Tailwind CSS

## 🛠️ Comandos de Desarrollo
| Comando                   | Acción                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Instala las dependencias necesarias.             |
| `npm run dev`             | Servidor local en `localhost:4321`.              |
| `npm run build`           | Genera la versión de producción en `./dist/`.    |
| `npm run preview`         | Previsualiza la build localmente.                |
